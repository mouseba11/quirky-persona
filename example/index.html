quirky-persona

Paste a title, press Generate, and see the persona and the writing instruction.

Same input and same seed always give the same instruction.

Opening this tab loads the sample and the config from Config. The title is scored against the patterns. A title with none of their trigger words uses the generic pattern.

    Test sample
    

    A title for the tester. Switching to Tester fills the form with this, and runs it with the config below.
    



    

    
  
  
  

    

    Language packs live in langs/. Switching language reloads that pack into the editor and the tester sample. Language support is rudimentary. The packs are demos. Proper localisation is left as an exercise for other quirky personas.
    


    Settings
    

    Press ? beside a setting to read what it does, and what changes when you edit it.
    

    

    


    Lists
    

    Each list works the same way: edit a row, move it, delete it, or add one. Order matters, because a seed picks by position.
    

    


    Patterns
    

    One block per pattern. Edit opens the actors for that stance, then its trigger words and templates. Leave a pattern's own list empty to use the shared list above. A pattern with no triggers is the generic fallback. Number means one of the number strings, such as 3 or three, selects this pattern.
    

    

    
  

    


    Config JSON
    

    This is the config the tester uses. Copy it into options.config, or into a JSON file you pass by path. The sample above is not part of it. Nothing is saved to disk.
